Method

Daily log returns of 19 listed Vietnamese banks (source: vnstock, VCI community edition). Rolling windows of 250 trading sessions, step 20 sessions: 88 windows ending 2019-10-09 through 2026-09-30. A pairwise correlation matrix is computed for each window.

Raw mode correlates returns directly. Residual mode regresses each bank's return on the VN-Index within the window and correlates the residuals, removing the market-wide component.

Two banks are linked when their correlation is at or above the threshold. In residual mode the threshold is by default chosen so the residual network has the same number of edges as the raw network in the same window. This matched threshold is never allowed below 0.05: a lower (possibly negative) threshold would treat opposite-direction co-movement as a link and give PageRank negative weights.

PageRank (damping 0.85, edge weights = correlations) is computed on the banks that have data in the window only. Banks without edges share their probability mass equally among active banks. Banks without data in a window are shown as N/A, never as zero.

How to read this app

  • Every point on the timeline is a 250-session window ending at that date; labels therefore read “window ending …”.
  • Raw and residual share one diverging color scale [−0.8, 0, +0.8], so switching modes shows how much connectedness remains once the market-wide component is removed.
  • Striped cells mean “no data in this window”. The diagonal is not a bank pair.
  • Selecting a bank highlights the same bank across Network, Matrix, Ranking and Timeline.
  • The balanced-panel line (dashed) on the timeline uses only the 15 banks present since 2019, so changes in sample composition are not mistaken for changes in co-movement.

Ranking tiers

The baseline is 1/Nactive (all active banks equal). A bank is Core when PageRank ≥ 1.5 × baseline, Periphery when PageRank ≤ 0.5 × baseline, and Middle otherwise; a bank with no edges is labeled isolated. Top PageRank scores are close: read the ranking by tier — differences below 0.5 percentage points are not meaningful. Numeric ranks appear only in tooltips. Tier stability across thresholds is checked in Analysis (Q4). This is a display convention, not a statistical test.

Data and missing values

15 banks have data from the first window. NAB joins in the window ending 2021-10-07, MSB and ABB in the window ending 2021-11-04, and OCB in the window ending 2021-12-02. The rise in residual connectedness in windows ending Apr–Oct 2022 coincides with these entries, so the timeline also shows the balanced 15-bank panel. SSB is excluded (short series).

Limits

  • Proxy network built from stock prices only — no bilateral lending or exposure data.
  • Co-movement does not imply causation, actual contagion, or systemic importance.
  • Centrality is not systemic importance: VCB and BID are large banks but sit in the Periphery/Middle tiers at default settings.
  • Ownership-group comparisons (Q3) describe groups only; bank size is outside the project scope.
  • The state–state group contains only 3 pairs; treat its average as indicative.
